Settings

Only demo admins see this page. Changing the MCip address or the client key disconnects every user: each user then connects their own key again.

The client key comes from MCip: Admin → API clients or Organization settings → API clients, shown once when the client is created or its key is rotated. It is stored encrypted and only its first 16 characters are ever shown here.

Developer info

The configuration this demo uses to call MCip, for reference while you build your own client. Keys never reach the browser: only the same 16-character prefixes MCip shows are listed here.

Your key travels to MCip as Authorization: Bearer; the system key as X-MCip-Client-Key. Both are stored encrypted on this server. Full walkthrough: Developer Guide; every call this demo makes is in the live API spec.

Connect MCip

Sign in to MCip, open your API keys page, create an External system (chat) key and paste it here.

The key is encrypted before it is stored. Only its first 16 characters are ever shown back, and it is never sent to the browser.

Revoke the key any time in MCip; the demo stops working immediately. Building your own client? The Developer Guide walks through the same flow, and the live API spec documents every call and event model.
